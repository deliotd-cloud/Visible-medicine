# Persistent head guided learning

The guided `/atlas/head-neck-3d` host retains one model iframe while moving
between authored, canonical linked-learning steps. Native same-origin history
supports Back/Forward; modified clicks and explicit fresh-view links remain native.
The original iframe URL is not changed by an in-place transition.

A strict source-revision/session/command channel requests the exact root or nested
structure. An acceptance acknowledgement is not proof of visible selection:
comparison links and source teaching unlock only after a source-bound selection
snapshot matches the requested concept. Stale sessions/sequences and foreign
frames/origins are ignored. The model remains responsible for exact source,
laterality, loaded/visible target and current study-owner checks.

Practice and in-model guided playback block step changes. Unsupported contexts,
different studies, hidden anatomy or connection timeouts offer a retry and an
explicit fresh-model fallback rather than silently resetting the camera or layers.
This does not promise camera interpolation across studies or patient-space
registration. CT/MRI remain separate reference subjects. No entitlement is granted.

Verification includes strict destination/result tests and an actual-component hook
harness covering history, retained iframe identity, acknowledgement-versus-rendered
confirmation, stale/foreign packets, practice lock, timeout and cleanup. Loaded
authenticated model/GPU acceptance is separate from these automated checks.
