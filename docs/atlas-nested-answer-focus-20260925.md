# Nested practice keyboard continuity

The generated regional viewer integrates Atlas `689835f`: after a named-space
answer or skip, focus moves to the feedback. Tab then reaches Next/Finish;
advancing places focus on the next question or results heading. This avoids
losing keyboard position when an answer button becomes disabled.

The source checks cover cardiac/ventricular practice, answer/skip/progression,
completion, and no focus stealing during renderer health/loading changes.
Desktop and narrow-screen browser samples are recorded in the main checkpoint.
These are not claims of native screen-reader, real-touch or full-device acceptance.

All model bytes, teaching, source licences, practice scoring/admission and
independent Atlas/case/lecture entitlements are unchanged. No patient data or
new imaging connection is included. Clinical approval remains revision-bound
and pending; the full regional/imaging roadmap remains active.
