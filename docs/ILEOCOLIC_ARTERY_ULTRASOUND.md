# Ileocolic artery ultrasound teaching draft

The source-bound FMA14815 lesson is an original educational draft, not approved
anatomy or patient-space correspondence. Only its ultrasound topic is changed.
The existing arterial evidence holds run before the new dispatch. Any changed
source identity, membership, geometry or review state refuses this lesson.

Primary references checked 20 October 2026:

- [2019 mesenteric-node study, Figure 1](https://pubmed.ncbi.nlm.nih.gov/31318849/):
  a healthy child's ultrasound example labels the ileocolic artery and vein.
  This is not an artery-detection study and establishes no visibility rate.
- [1997 ileocolic artery aneurysm report](https://pubmed.ncbi.nlm.nih.gov/9172672/):
  an abnormal case with Doppler discussion, not normal-artery visibility evidence
  or a current diagnostic recommendation.

The notes do not extend to named distal branches. No article figure, image,
abstract, scan, table, dataset or additional dependency is redistributed.
References are citations only; no reuse right in the publications is asserted.
Existing BodyParts3D attribution and source restrictions remain unchanged.

Run `npm run ileocolic-artery-ultrasound:test` from this Atlas checkout. It checks
all 9,936 root-body teaching placements, exported records and review packets
against the exact prior source, refuses changed identities and stale/tampered
review material, and renders the actual explorer note callback. It is not a
production build, browser/GPU check or clinical acceptance.

Radiologist review must still verify source identity, boundaries, relationships,
terminology and the limited ultrasound claims against this exact teaching
revision. Source meshes, accepted CT/MRI masks, private cases, entitlements and
the desktop clinical PACS are unchanged. Website ingestion requires the normal
source-bound Review/export pipeline; this candidate is not a public release.
