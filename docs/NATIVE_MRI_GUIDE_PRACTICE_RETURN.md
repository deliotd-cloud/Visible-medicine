# Returning from native MRI practice to Guided learning

In private Regional MRI Review, start a guided path, explicitly select its saved
annotation or variant, then choose **Try structure check**. Practice remembers
that exact guide origin privately in memory; it does not display tour captions,
guide names or the origin's answer during questions. Changing question activity
or choosing **Next structure** preserves the origin without recording progress.

- **Return to guided step** revalidates the exact source package, sequence,
  guide revision, step and previously chosen annotation. It loads that annotation
  only, retains the previous question paused during verification and canvas
  drawing, then restores the guide. Its heading receives guarded one-time focus.
- **Return to inspection** leaves the question on the currently practised
  annotation. It does not restore a guide or load another structure.
- While a guided return is pending, its return action is replaced by
  **Cancel return to guide**. Cancellation restores the previous question/view
  and prevents late loading or paint from restoring the guide.

Verification failure retains the previous question without substituting another
variant, nearby structure or sequence. Source/sequence replacement retires the
origin; stale callbacks cannot use it. Existing unsaved-correction protection
remains. Ordinary annotation practice has no guided-return action.

The origin is an opaque, frozen local capability with no exposed answer fields.
Actual loader ownership and exact guide membership are required, not merely
matching IDs. It is neither a bookmark nor stored progress: reload/reset removes
it. No source images, masks, annotation statuses, models, access rules, scores,
completion or clinical approvals are changed or saved.

This is private formative navigation, not learner release, a scored exam or
patient-space synchronization. Synthetic loader/component checks do not establish
real-package, browser/GPU, keyboard hardware, screen-reader or clinical acceptance.
