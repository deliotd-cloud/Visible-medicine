# Compare saved review material

The protected Saved inspections page can compare a personal-review candidate
with its explicitly superseded predecessor. Open **Compare changes**, then choose
a structure. Both columns refer to that same structure in their own saved version.
The selector does not change the independent editable worksheet below. Links to
a saved worksheet open its default selection; choose the intended structure there.
Saved-model links carry the verified structure and source for their own package.

The comparison is read-only: it does not read personal review events or copy
decisions, notes, evidence, attestations or approvals. Open the earlier candidate
separately to inspect its records. Supersession is not clinical acceptance.

## Historical identity and delivery

Both immutable descriptors must verify independently, name a direct supersession,
and contain exactly the same structure-ID set. Each worksheet is requested only
when comparison is opened, through the existing protected asset route. Every
request retains Clinical Review and administrator-model authorization, same-origin
credentials and private/no-store delivery. No new route, permission or datastore
is introduced. Responses are streamed with a 2 MiB bound and checked against the
descriptor's exact byte count and SHA-256 before decoding.

The historical decoder accepts only the known frozen inspection/personal-review
packet versions. It checks bounded fields, source/model/query identity, blank
review placeholders, checklist basis where present, and each packet's own
canonical source/teaching/checklist/material fingerprints. It imports no current
catalogue, display pins, lesson resolver, tour catalogue or decision validator.
Thus a legitimate older lesson is not rejected merely because current teaching
has changed. Saved JavaScript is not executed for comparison. Unknown future
schemas require a separately audited decoder; there is no live-material fallback.

Both columns clear on access/integrity failure, close, pair or selection change.
Cancelled or late responses cannot repopulate a different comparison. The table
distinguishes material/source/teaching, worksheet, renderer, model inventory and
checklist changes. V1 descriptor checklist evidence is marked unavailable, not
unchanged. Complete saved teaching remains expandable and is rendered as text;
external reference links require HTTPS.

## Verification and remaining scope

Synthetic contract, decoder, actual-component and server-page tests cover success,
historically changed teaching/tours, malformed/mixed identity, denied/corrupt/late
responses and retention of the independent saved worksheet. A local evidence probe
also reconstructs both registered historical worksheets from screened source and
checks their exact registered byte counts/digests before decoding; it does not
read private frozen-package objects.

This is the same-selection root-body comparison slice of BASE-04. Wider shoulder,
nested/specimen scopes, real signed-in visual acceptance and revision-bound
radiologist sign-off remain separate. It does not establish scan registration,
publish material, transfer approvals or complete the full platform checklist.
