# Reviewing selected course content

Course editor → Preview → the saved release opens a staff-only course preview.
Selected course content lists only that release's saved workbook selection, in
its saved order. Unselected items are not added. An item absent from the current
authorised Studio snapshot, or belonging to another course, keeps its position
as “Selected item unavailable”; no identifier, foreign title or substitute is
rendered.

The release version describes the current saved release metadata and selection.
Each visible workbook's title, type, version and status comes from the current
saved Studio snapshot. These rows are not frozen slide/case content, an archived
review snapshot, or proof of independent approval. The page says so explicitly.
Use the existing editor and revision-bound review workflow to inspect content.

This is an outline preview, not learner playback. Enrolment and payment actions
remain disabled, private releases stay staff-gated, and Atlas, case and paid
lecture access remain separate. No schema, authentication or publication change
is required.

Verification includes ordered/reversed snapshots, missing/wrong-course rows,
empty selection, escaping, live revision labels, authentication refusal and
not-found handling. The desktop layout fixture uses the exact outline and CSS
with synthetic data only; it does not bypass or validate signed-in production
access. Evidence: E:/VisibleMedicine-LocalStaging/20261008-release-content-preview.
