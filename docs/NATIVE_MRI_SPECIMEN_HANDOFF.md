# Explicit existing 3D specimen → native MRI selection

In private Regional MRI review, load the independently bound local package and
choose a sequence and accepted-scoped annotation. Open its existing detailed
3D specimen beside MRI. After the frame confirms a fresh source-bound selection,
select another supported knee structure in that model. A **Show [structure] on
MRI** button appears only for a unique authored counterpart in the same loaded
sequence. Nothing changes on MRI until that button is pressed.

The action verifies the saved annotation through the existing loader, focuses
its geometry in the current native plane, shows its overlay and retains a
compatible specimen frame. An explicit alternate choice leaves the old guided
step. Practice cannot use the action to replace its question. Dirty corrections
retain their existing discard-confirmation protection. Closing a reference while
verification is pending does not reopen it on completion.

## Scope

This is semantic navigation between different anatomical references, not
registration, mirroring, a shared patient, segmentation propagation or a
cross-sequence cursor. The current tested MRI candidates are partial left-sided
annotations compared with an independently right-source specimen; the side and
coverage warnings remain. Neither a source-declared acceptance nor a passed
software check approves anatomical correspondence or a public release.

No cross-scan search or automatic sequence switch occurs. A grouped/whole-parent
surface, ambiguous or duplicate mapping, held or provisional annotation, missing
geometry, wrong source/side/revision or stale channel/session offers no substitute.
Copied reports cannot become live selection authority. Hidden pages, blocked
model practice, retry, replacement and close retire reports. Only public model
identities travel to the existing iframe; no MRI revision, image hash, annotation
identifier, voxel, mask or private coordinate is sent in these messages.

## Numerical native-focus correction

The actual package probe exposed an exact-boundary floating-point roundtrip
failure in the saved quadriceps-tendon focus. Its rounded native voxel remains
inside the verified mask. Native focus now uses the same 1e-6-voxel edge tolerance
as existing markup projection and clamps only that numerical residue. Real
out-of-source geometry still refuses. No source grid, mask, accepted boundary or
clinical decision changes. A pre-fix regression retains six original passes and
the new failing boundary case before the correction.

The read-only actual-loader probe exercised six partial/opposite-side candidates
in two sequences, fourteen ordered within-sequence handoffs, forty-two native
focus/visible-geometry frames and copied/stale-report refusals. It is not an
exhaustive dataset audit, signed-in browser/GPU check or clinical sign-off.

All original viewer and inspection test bodies remain; new cases cover explicit
clicks, no automatic changes, source/lifecycle retirement, pending loads, practice
and corrections. Exact verification and scoped recovery evidence is under
`F:/VisibleMedicine/staging/20261014-mri-specimen-handoff/` and
`F:/VisibleMedicine/recovery/checkpoints/20261014-mri-specimen-handoff/`.
Only a passing actual terminal checkpoint establishes completed recovery.
