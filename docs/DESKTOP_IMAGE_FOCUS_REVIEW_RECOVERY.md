# Desktop image focus and Review filter recovery

16 October 2026. Local-only UI candidate on unchanged Atlas source `58926355`.

## Native CT/MRI images

Choose **Focus images** in the loaded CT or MRI head viewer to give the image
workspace the width used by the two side panels. **Restore panels** brings back
the structure index and learning panel. They stay mounted: their local drafts,
search, selection and independent scroll state are not discarded. The image
workspace keeps its native study, slice, windowing, overlays and existing tools.

This option is available only in ordinary structure-information mode. Practice,
guided learning, a comparison, study closure/replacement or unavailable context
immediately restores the panels and retires focus mode. It does not hide a live
question, caption, comparison or score. Keyboard workspace shortcuts restore a
hidden panel before moving focus there; typing and background loading do not
move focus. The normal three-panel layout remains the default.

## Clinical Review inbox

**Reset filters** appears only when a filter differs from the initial view. It
restores empty search, all areas, known items needing review, all change reasons
and page one. It keeps the current loaded scan and returns keyboard focus to
search after the reset commits. It does not scan again, navigate, save, approve
or change access. Old/abandoned controls cannot reset a replacement source or
account context. Empty results distinguish restrictive filters, an incomplete
scan and no known outstanding items in a completed scan, without claiming approval.

## Boundaries and acceptance

No source image, mask, accepted boundary, model, teaching, entitlement, private
decision or desktop PACS is changed. No new asset, dependency, font, fee, schema,
permission, public deployment or off-device backup is introduced. The normal
Review binder explicitly includes the native shell, shortcut component, CSS and
focus helper, then its production viewer is regenerated. Existing approvals do
not migrate across a changed renderer binding.
