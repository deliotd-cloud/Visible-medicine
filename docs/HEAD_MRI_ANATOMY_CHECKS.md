# MRI only anatomy understanding checks

Four draft checks accompany the existing left and right amygdala, corpus
callosum and pituitary selections in MRI and the linked 3D Atlas. They supplement
click-on-mask identification practice without adding a permanent panel.

## Learner use

Select a supported MRI structure, open Learn this anatomy, then Check
understanding. The same folded control accompanies common teaching in its
existing 3D target. Select one radio option and press Check answer. The first
submitted answer stays locked while that question view is mounted, including
when its disclosure is closed and reopened. A different structure, source or
surface starts a separate view. Nothing is saved as a score or completion.

These questions test general anatomy and function, not normality or measured
function in the displayed study. The callosal mask covers a regional portion;
the gland label does not resolve individual lobes, stalk or cell populations.
MRI and the generic 3D model are separate, unregistered subjects. No exact CT
counterpart is substituted for any of these four concepts.
