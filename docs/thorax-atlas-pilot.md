# Thorax anatomy pilot

`/atlas/thorax-3d` uses the original regional explorer, not a diagram or reduced
replacement. It has 157 regional and nine nested source selections, chest-wall
dissection, system switches, search, isolate/fade, separation mechanisms and
cardiac/pulmonary studies. Draft teaching stays in the existing collapsed panel.
The page reuses the compact website anatomy frame and keeps scope/credits below
the working surface in one collapsed section.

Its source-derived runtime is shared with head/neck at
`/atlas-runtime/head-neck/index.html?region=thorax`. The module manifest names
the exact Atlas commit, input hashes, per-region targets and 52-model union.
Existing default head/neck links remain unchanged. The website does not rewrite
catalogues or duplicate shared models. Use the source exporter and the normal
[lossless model-delivery procedure](atlas-model-delivery.md), never hand-edit an
export. The three other runtime exports remain independently source-bound.

All geometry retains its admitted BodyParts3D v4 CC BY 4.0 source and attribution;
software notices are included. No new dependency, font, paid service, patient
scan, mask or lecture asset is added. Missing nerves/partial vessels remain
disclosed; cardiac spaces are not chamber walls. Source counts are not complete
anatomical coverage or radiologist approval.

There is no connected scan or patient registration. Future case navigation uses
Didanix Education/light with separate case and paid-lecture authorization. This
pilot does not connect the independent Atlas review database or grant access.

Verification combines actual source/link/export checks with desktop and
phone-width browser sampling. Refer to the main task's dated shared-regional
checkpoint for the actual sample, source/GitHub/D and private-publication outcome;
do not infer successful deployment from this document. Physical-device and
revision-bound clinical acceptance remain open. Abdomen still requires its full
nested studies and independently licensed specimen dialogs before website parity.
