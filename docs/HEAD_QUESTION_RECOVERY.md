# Recovering an unavailable head-atlas practice question

CT/MRI practice shows **Question unavailable** when the exact saved annotation
cannot be read or has no usable saved mask. Learners can retry that same annotation
or skip it and continue the existing set. A retry neither replaces the annotation
nor records an attempt. A skipped annotation remains unanswered in the completed
review; correct/incorrect/revealed first-attempt scoring is unchanged.

Retrying, advancing, ending, or replacing the study aborts superseded loads;
late results cannot restore an obsolete question. Keyboard focus follows the
question heading through opening, failure, retry and successful load. Error text
uses the existing alert, and feedback retains its existing heading focus.

This is session-only educational practice, not durable exam results, diagnostic
validation, clinical approval, or CT/MRI-to-reference-model spatial registration.
No native files, masks, source pins, eligibility rules or access gates change.
