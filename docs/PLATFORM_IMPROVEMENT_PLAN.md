## Priority order and completion evidence

1. **Reliable integration baseline.** Resolve current regressions and stale
   delivery assertions against exact saved source checkpoints. Preserve original
   failures, historical fixtures, byte checks, rights/privacy holds and negative
   cases. Do not mechanically replace historical pins across the suite.
2. **CT/MRI and existing 3D Atlas learning journeys.** Extend only explicit,
   source-bound anatomical concepts. Maintain laterality and partial-scope
   qualifiers, clear return navigation, and unsupported-target refusal. Verify
   search → structure → other modality → existing 3D target and return. Separate
   semantic comparison from spatial registration; the CT, MRI and generic 3D
   subjects must not be presented as registered anatomy.
3. **Didanix Education web delivery.** Inspect the actual Education/light web
   contract before implementing protected media transport. Preserve independent
   Atlas, case and paid-lecture entitlements. Require fail-closed authorization,
   explicit source/revision binding and cleared data handling before private
   deployment. Never substitute an invented endpoint, client-only entitlement
   check or desktop clinical-PACS modification. Browser-local folder import is
   useful testing, not completion of authenticated delivery.
4. **Guided learning and assessments.** Improve purposeful cross-modality tours,
   smooth camera motion, exact-structure checks, feedback, keyboard operation
   and recovery. Hide answer-revealing controls during assessment. Retain
   first-attempt scoring and distinguish session-only from saved results.
5. **Premium desktop experience and authoring.** Reduce duplicate controls,
   scrolling and dead ends; keep the image primary. Improve course/Studio
   organization and loading, empty, error and access-restricted states. Preserve
   existing author work and avoid schema changes without an actual requirement.
6. **Anatomical/content coverage and quality.** Fill source-supported regional
   gaps and concise anatomical, functional, clinical and imaging teaching.
   Prefer already-cleared assets; never infer accuracy or commercial rights
   from AI generation. Keep draft qualifiers and source/asset notices intact.
7. **Release readiness.** Use risk-matched checks during development, then
   applicable access/privacy/licensing, source-integrity, desktop browser,
   accessibility, performance and recovery checks for an exact release candidate.
   Clinical acceptance and hosting authority remain separate release gates.

Urgent safety, access-control or correctness defects take precedence over this
order. A gated workstream never prevents useful independent work elsewhere.
