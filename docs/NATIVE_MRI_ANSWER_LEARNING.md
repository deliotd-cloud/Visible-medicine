# Study a regional MRI practice answer

In private Regional MRI Review, load the independently bound local package,
choose a sequence and an accepted-scoped saved annotation, and start Structure
check. After a correct naming/location answer or an explicit reveal, an optional
initially closed **Study this answer** section appears where an exact current 3D
reference is available. A reveal remains a reveal, never a correct attempt.

Choose a named reference to inspect it beside the MRI without replacing the
question or its feedback. The existing reference teaching disclosure remains
lazy and closed until requested. Multiple references require an explicit choice;
same-structure, whole-parent, grouped-surface and opposite-side/unmirrored limits
remain visible. A separate Atlas tab is optional and labelled as such.

The saved MRI extent is not assumed complete anatomy. These are independent
semantic references, not a spatially registered patient model, source-normality
assessment, diagnostic tool, approval or scored examination. No new anatomical
correspondence is invented, teaching is not inferred from an accepted annotation,
and no provisional annotation is promoted. No scan/mask/coordinate/private source
identity is transported in the public reference link.

## Ownership and lifecycle

- Followup content is not mounted before correct/revealed current feedback.
  Off-annotation or undrawn views and retired source/annotation/question contexts
  withhold it; location feedback additionally requires its matching display view.
- The existing canonical 3D comparison validator and native MRI package ownership
  are required. Copied/mixed/stale/provisional/malformed contexts refuse.
- Inspect buttons revalidate their explicit target after the committed render.
  Stale/speculative/unmounted handlers cannot launch a replacement reference.
- Opening/closing a reference preserves the question instance and loaded source.
  Starting another unanswered activity closes an answer reference; source changes
  keep the existing cancellation, unsaved-correction and retirement rules.
- No score/history, private source write, new approval/access rule, desktop PACS,
  dependency, model, dataset, font or fee is introduced.
