# Visible Medicine source-only recovery

Thirty-three selected native and website source, test and non-patient coverage metadata files for the installed prostate selection milestone. Native files preserve committed LF bytes, verified equivalent to the clean Windows CRLF checkout. Excludes generated runtime bundles, binary models, scans, masks, private databases, MRI lookup records, credentials, screenshots and canonical Git ancestry. This is a selected-source recovery checkpoint, not a whole-project or patient-data backup.
