# CT/MRI selection history

Browser Back and Forward retain an ordinary selected structure even when it has no 3D concept link, alongside its existing scan layout, slice and window settings. Explicit Clear remains empty. Canonical concept, guided and practice navigation retain their own policies.

Only an opaque token enters browser history. Selected identities and exact bounded annotation snapshots remain in tab memory; restored entries must match the current image, study, modality, source revision and annotation. Changed annotations, unavailable or duplicate entries, evicted receipts, new sessions and closed packages cannot restore an old selection. No spatial registration or access entitlement is implied.

Verification uses the actual React viewer with synthetic image acquisition and native browser traversal for CT and MRI, plus complete existing regression roots, full configured types and production build. Synthetic browser evidence is not real-account or clinical acceptance.
