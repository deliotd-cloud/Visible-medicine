# Reporting an Atlas problem

Report a problem is a collapsed action under Linked teaching in the generic 3D regional/whole-body viewer and below Study information in CT/MRI head's Structure panel. It copies a small text template; it does not send a report. Add what happened and the steps to repeat it when contacting Visible Medicine. Reviewers can open the existing access-controlled Clinical Review inbox in a new tab.

Only the atlas type, region, exact source revision and acknowledged catalog structure ID/name are included. No URL/query, local filename, study/patient/session identifier, image/mask, coordinates, free text, quiz target or answer is collected. Root selection must be confirmed in the current 3D frame/document; CT/MRI requires the actual loaded entry in its current package. Practice, loading, replacement, retired or hidden contexts refuse copying. Browser clipboard failure offers manual selection with a fresh check on native copy/cut. Nothing is persisted or uploaded.

The source revision is the 3D runtime commit or CT/MRI manifest digest, not a clinical approval or spatial-registration claim. Existing reviewer authentication and independent entitlements remain. This first increment does not create a report inbox or permit learner review decisions. Other standalone specimen/shoulder runtimes, US and X-ray need their own verified current-selection adapters before expanding this action.

The website integration binding includes the shared component, stylesheet and context validator. Rebuilding creates a new presentation revision without migrating approvals. Changes remain in an isolated local candidate until the owner authorizes installing them.
