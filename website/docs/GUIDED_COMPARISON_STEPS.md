# Moving through a linked comparison

Compare views activities offer compact Previous/Next structure links directly below the heading. The links follow the authored sequence in the same tab, so browser Back/Forward retains normal activity history. Start/end markers do not imply recorded learning completion. The catalogue return remains available above the heading.

Each destination is rebuilt by the existing strict, revision-bound comparison resolver. Only the immediately adjacent concept may be linked. A missing mapping shows an unavailable marker; it is never skipped or replaced with a general Atlas destination. Malformed, duplicated, stale or extra URL fields cannot produce a handoff. CT/MRI/3D availability stays specific to the target concept, including CT-only bone and CT/MRI-only examples.

Image/model cards continue to open separate tabs and apply their own access checks. Changing this activity does not move those tabs, load medical images, register separate subjects, store answers/progress or grant access to paid resources. Existing clinical content, accepted masks and source revisions are unchanged.
