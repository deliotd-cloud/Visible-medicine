# Finding course content

The course Content pane provides title search and a content-type filter. Both act only on the current course-scoped outline and keep the original saved learner positions. Filtering neither saves nor reorders the release. Generic unavailable saved positions remain visible without exposing missing or out-of-course identifiers.

The controls are temporary, course-scoped view state. Changing course resets their effective values. Clear filters restores the complete outline. The result count describes available matching content; unavailable saved positions are counted separately. Course details, add-content and release forms stay mounted, preserving their independent unsent-input protection.

No access, publication, draft persistence, server mutation, route, schema, entitlement or clinical-review policy changes. The Education response helper inherited from the parent remains inert: no media route or readiness is enabled.

Current Studio test source identities are advanced to this exact component. The historical component, original assertions and case inventory remain byte-exact; original preimages and exact receipt ancestry are retained locally.
