# Returning to a linked tour

The comparison page offers Back to this tour. It creates a same-origin catalogue URL from the already validated sequence label, with all mapped views and the head/neck region. All 45 mapped activities return to a first compact page containing the correct tour.

This is a contextual tour return. It does not restore the previous search, modality filter, page number, expanded state or scroll position. It works on direct links and after adjacent-step navigation without browser history, local storage or caller-supplied redirect state. The comparison resolver still requires the same four exact revision-bound keys; scan/modality links and independent access checks are unchanged.

No scan, model, score, completion, clinical approval or patient-space registration is created by the link.
