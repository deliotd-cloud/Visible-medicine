# Included draft anatomy model

`bodyparts3d/shoulder-right.glb` contains eleven original BodyParts3D source meshes with a common coordinate transform. See its manifest and credits page for CC BY 4.0 provenance, bindings, modifications and required attribution. These rights-cleared anatomical surfaces are included for draft education, not claimed as independently clinically validated. See `docs/MESH_INGESTION.md` for release gates.
