# Hyoid, tongue, palate and laryngeal muscle drafts

## Scope

Fourteen definitions provide 54 new Anatomy/Function drafts for 27 existing entries: eight bilateral hyoid muscle types, genioglossus, hyoglossus, levator/tensor veli palatini, a midline uvular entry and bilateral thyro-arytenoid. No UI control, mesh, package, scan, patient data or approval is added. Current panels and stable identities are reused.

Notes distinguish fixed-hyoid versus fixed-jaw actions; inferior mental-spine geniohyoid versus superior-spine genioglossus; C1 fibres travelling with XII versus true hypoglossal motor supply; digastric V3/VII supply; ansa cervicalis versus thyrohyoid; palatal V3 versus vagal supply; and recurrent-laryngeal supply. Thyroid cartilage is not the thyroid gland. Tendon reflection, tongue deformation, palatal closure and voice are described as teaching relationships, not validated simulations.

## Source limits

The official v4 IS-A index and existing catalogue agree on all 27 names/component memberships. Left digastric groups FJ1555/FJ1560/FJ1578, right FJ1556/FJ1579; the index does not independently name these files as anterior/posterior bellies or an intermediate tendon. Left thyro-arytenoid groups FJ2784/FJ2785, right FJ2802/FJ2803; no independent vocalis/layer identity is assigned. File count is not anatomy-part count. Omohyoid remains one component per side despite its two-belly teaching description. FMA46733 remains a midline uvular source, not separately identified left/right bundles. No prior source hold is lifted.

Milestone body totals: Anatomy 451 draft / 571 identity-only; Function 506 draft / 146 identity-only / 370 pending. Fourteen head/neck muscle Function entries remain pending. Specialist topics and quizzes are unchanged; draft status does not establish complete function, anatomy or clinical coverage.
