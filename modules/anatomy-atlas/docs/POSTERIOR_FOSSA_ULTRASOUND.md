# Posterior-fossa ultrasound orientation drafts

Four existing nested selections now have an explicit Ultrasound topic: midbrain,
pons, medulla and grouped cerebellum. These are four introductory educational
drafts, not four newly segmented structures or complete ultrasound curricula.
The source compounds, immutable teaching identity pins, geometry and all other
topics remain unchanged. X-ray remains pending. No age, modality or diagnostic
approval is inferred from an adult surface.

Open **Dissect brain → Brainstem and cerebellum**, select a part, then expand
**Learn more → Imaging → Ultrasound**. A direct component-imaging link selects
the same source-bound part and topic. The existing compact panel is reused;
there is no new toolbar, default panel or acquired scan connection.

## Evidence and scope

Primary references checked on 17 October 2026:

- [AIUM neurosonography practice parameter, 2024 revision](https://onlinelibrary.wiley.com/doi/10.1002/jum.16551): neonatal/infant sagittal brainstem/aqueduct assessment, fontanelle limitations and additional posterior-fossa windows. This is not a routine adult transcranial visibility claim.
- [Chen et al., 2021](https://www.frontiersin.org/journals/neurology/articles/10.3389/fneur.2021.770908/full): an observational study of pontine/medullary measurements in 67 healthy term and 36 preterm neonates. Medullary measurements used the foramen-magnum window. The lesson supplies neither a universal growth threshold nor an individual outcome prediction or procedural instructions.
- [Steggerda et al., 2015](https://pubmed.ncbi.nlm.nih.gov/25899415/): retrospective comparison in 113 high-risk term infants. Mastoid-fontanelle views improved detection, but MRI identified abnormalities not seen on ultrasound. Results are not generalized to all infants or adults.

The full AIUM and publisher-hosted Chen texts were accessible. The Steggerda
PubMed indexed abstract was available through search; direct page retrieval was
intermittent. The lessons paraphrase only supported facts and retain population,
acquisition and model limitations. A source link is not institutional endorsement.

Only original brief text and links are added. No third-party sonogram, figure,
table, reference database, scan, mask, font, texture, model, package or API is
included. Existing code/text and model licences and attribution obligations are
unchanged; access to a reference is not a licence to redistribute its assets.

## Source and review contract

`content/posterior-fossa-ultrasound.ts` holds the four drafts and scoped reference
titles. `content/nested-teaching.ts` attaches only their Ultrasound fields to
the four existing concepts. Source/side/parent/study/bundle guards still determine
whether a concept can resolve. Shared reference URLs do not silently relabel
unrelated review packets.

`npm run posterior-fossa-ultrasound:test` compares the complete actual concept
and reference graph with the recorded pre-change Git module graph, exercises
the actual lesson/component/review path and rejects stale source/revision data.
Historical validators reverse only these exact hash-verified additions before
checking their original snapshots. Those checks are not clinical, physical-device,
GPU, diagnostic or production-role acceptance.

The four current teaching revisions require fresh radiologist review. The
existing renderer fingerprint conservatively includes teaching dependencies and
the package manifest, so regenerating it also advances the display/geometry
revision in all 108 nested Review contexts. Source GLB bytes and frames remain
unchanged; this is not a geometry correction or a migration of prior approvals.
Old display revisions must be rejected before storage. Source identity and
geometry revisions are not approvals; imaging registration remains unavailable.
There is no acquired ultrasound package, sonographic plane, infant
mesh, diagnostic measurement or patient correspondence. CT/MRI remain separate
subjects. Atlas, cases and paid lectures retain independent access rules.

Clinical review should verify the age/window language, study limitations, wording
of non-exclusion of injury, actual source scope and the absence of implied adult
visibility, prognostic cut-offs or caliper guidance before publication.
