# Thoracic small-vessel MRI teaching

Five exact retained source selections receive original MRI orientation/limitations
drafts: oesophageal artery (FMA4149), variant bronchial artery (FMA10704),
bronchial artery (FMA68109), grouped oesophageal branches (FMA71537), and
anterior cardiac vein source group (FMA76767). The existing MRI panel is reused.
No navigation controls, meshes, scans or correspondence records are added.

## Evidence and scope

- Bronchial teaching cites the original cystic-fibrosis MRI study
  ([Leutz-Schmidt et al.](https://pubmed.ncbi.nlm.nih.gov/37009019/)).
  Detection of pathological dilatation is not evidence that routine MRI resolves
  normal bronchial arteries, every variant origin or spinal arterial connections.
- Cardiac teaching separates anterior cardiac veins from the anterior
  interventricular vein in the original [Younger et al. CMR study](https://pubmed.ncbi.nlm.nih.gov/19671132/).
  That study does not validate MRI visibility of this retained anterior cardiac
  source group. The university vein table supports anatomical orientation only.
- Oesophageal entries explain the absence of supporting MRI detection evidence
  in their cited anatomy source. They do not establish a negative universal
  claim that these arteries can never be imaged. A draft status measures
  editorial coverage, not validated imaging correspondence or detectability.

Reference pages are factual reading links, not licensed image assets. All
teaching wording is original. No article figures, tables, datasets, scans or
publisher prose are redistributed; existing project licences and attribution
remain unchanged.

## Binding and verification

`content/thoracic-small-vessel-mri-pins.json` records complete source identities,
bundle bytes/hashes, the catalogue and exact prior MRI lessons at source parent
`84ed21b1ad446039ac4210d6a02e0bb0bfd553dd`. A full source identity must match
before a lesson is returned. Run `npm run thoracic-small-vessel-mri:test`.
Tests distinguish the five intended changes from all other topic placements,
check source mutations and preserve the remaining held structures.
The focused source test preserves 9,931 other topic placements and rejects 75
altered identities. The companion Review test exercises all five actual note
renderings and current packets, rejects 15 stale/altered packets and refuses ten
stale save requests before private storage is touched. Exactly five Review
display pins change; 1,099 others remain unchanged. These are automated checks,
not proof that a vessel is represented accurately or visible on a clinical scan.

Generated teaching and protected Clinical Review must be imported together into
the separate website checkout. Source tests are not browser/GPU acceptance.
All drafts require the radiologist's exact-revision teaching/anatomy review;
no existing clinical approval transfers. The generic 3D model is not spatially
registered to a patient scan. Case, Atlas and paid-lecture access stay independent.
