# Mediastinal vessel chest X-ray teaching

25 September 2026. Five original drafts fill pending X-ray tabs for the existing
ascending aorta, arch, descending thoracic aorta, SVC and azygos vein selections.
They appear in the existing Imaging panel; no navigation or geometry is added.

Exact original central-vessel source identities must match. Names or FMA IDs
alone do not bind a lesson. Unspecified/midline source laterality is retained.
Other modalities, structures, dissection recipes and access rights are unchanged.

## Reference and reuse boundary

Factual references, accessed 25 September 2026:

- [Radiology Masterclass: mediastinal contours](https://www.radiologymasterclass.co.uk/tutorials/chest/chest_home_anatomy/chest_anatomy_page9): arch, descending interface, aortopulmonary window.
- [Radiology Masterclass: aortic unfolding](https://www.radiologymasterclass.co.uk/gallery/chest/mediastinum_hilum/unfolded_aorta): elongation versus aneurysm.
- [Radiology Assistant: heart failure](https://radiologyassistant.nl/chest/chest-x-ray/heart-failure): SVC/pedicle, projection and azygos prominence. No numerical diagnostic cut-offs adopted.
- [Radiology Assistant: basic interpretation](https://radiologyassistant.nl/chest/chest-x-ray/basic-interpretation): azygo-oesophageal interface and azygos fissure distinction.
- [ACR/RSNA: chest radiography](https://www.radiologyinfo.org/en/info/chestrad): modality context and limitations.

These are reading citations, not asset licences. No publisher text, figures,
screenshots, PDFs, scans or datasets are bundled. Existing BodyParts3D attribution
remains; no dependency, fee or new asset is introduced.

topics, source mutations, wrong-vessel content, viewer rendering, export contracts,

or diagnostic performance is validated. Any later linked case requires its own
privacy/release approval and case entitlement; Atlas access does not grant a paid
lecture subscription. Live-site integration/publication is recorded separately.
