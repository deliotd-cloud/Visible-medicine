# Direct anatomy results before contextual study views

When an Everything search returns structures, study views matching only their
included anatomy are placed in a collapsed, keyboard-operable disclosure. Study
titles matching the query stay in the main list. Explicit study-only searches,
empty queries and searches with no structure result retain the ordinary list.

The distinction matters: a bone may appear as background in a muscle or vessel
recipe without being its teaching focus. The related section explains that;
it does not imply anatomical equivalence, a verified relationship or complete
coverage. No match is removed. Existing ordering within each group, source-bound
actions, side filters, aliases and nested dissection links remain intact.

Opening a related study still shows the existing reset warning and requires
confirmation. Cancelling does not alter the model. Exam guards remain. A new
query starts with related results collapsed; explicit study-only filtering lists
them directly. Each group retains the existing incremental result limit.
