# Thoracic spine guided learning — draft

The six-stop **Thoracic spine: vertebrae and whole discs** tour uses eleven existing BodyParts3D 4.0 source records: eight selected thoracic vertebrae (first, second, fifth, sixth, eighth, ninth, eleventh and twelfth) and three whole discs labelled for the first, fifth and eighth thoracic vertebrae. The bones remain available as context. No mesh, source transform, bundle or licence changes are required. The tour is registered in the source application's regional and whole-body Guided learning selectors for local draft review. Website import and public release are separate stages, not established by this source change.

## Sequence and teaching boundary

1. First thoracic vertebra, anterior: identify the body and orient the posterior arch with the second vertebra nearby.
2. First source-labelled whole disc, left: compare with the first and second bones.
3. Fifth source-labelled whole disc, left: compare with the fifth and sixth bones.
4. Eighth source-labelled whole disc, posterior: orient with the eighth and ninth bones.
5. Eleventh thoracic vertebra, posterior: compare posterior elements with the twelfth bone.
6. Twelfth thoracic vertebra, left: compare body and arch with the eleventh bone, then distinguish this source view from future acquired imaging.

Each stop has an explicit source-bound frame, 14-second reading interval and faded surrounding surfaces. The shared player supplies its usual camera transitions, pause, step selection and reduced-motion behaviour. The tour does not add a control or a separate viewer.

Disc names deliberately retain the original source's vertebral labels. These are whole-disc surfaces, without independent annulus, nucleus or endplate segmentation. Adjacent bones provide orientation, not validated radiological level numbering. The T12–L1 disc is unresolved and absent, so the final stop is bony only. The canal, cord, nerve roots, ligaments and individual joints are not established by these selections. No disc measurement, pathology, surgical plane, patient registration or scan correspondence follows from a camera view.

## Source and review gates

The playback gate binds the complete tour text and sequence to the exact eleven displayed records, both original bundle metadata records, source version, CC BY 4.0 licence and coordinate system. Missing, duplicate or changed source identities or bundle metadata fail closed. The pin script additionally verifies the local GLB file lengths and SHA-256 values during source validation; playback does not independently hash bytes fetched by the browser. An unchanged catalog is therefore not proof of unchanged remotely served mesh bytes. The record pins preserve source credits; no scan, copied figure, texture, asset, fee or dependency is added.

The anatomical reading is [TTUHSC El Paso's back-bone table](https://anatomy.ttuhscep.edu/anatomytables/bones_back.html), used for facts about thoracic vertebrae and rib facets, with original caption wording. [RadiologyInfo's spine MRI](https://www.radiologyinfo.org/en/info/spinemr) and [spine CT](https://www.radiologyinfo.org/en/info/spinect) pages only explain possible future imaging comparisons; neither supplies an image or alignment for this tour.

The owner-radiologist must review this exact tour revision and the independently bound geometry/display and teaching evidence before approval or learner release. The shared selectors do not enforce a clinical approval entitlement: an imported draft is playable wherever that runtime is exposed. Keep this change local/private pending that review and an explicit release decision; the draft label is not a release gate. Review should inspect every selection, label, source extent, anterior/left/posterior frame, fading and caption in a real viewer. Source checks and a successful build alone cannot establish anatomical correctness, smooth rendering or clinical acceptance. Atlas, imaging-case and lecture access remain independent; no imaging link is admitted without separately cleared images and validated mapping.
