# Limb-nerve relationship checks

Select an existing forearm, thigh or leg muscle, open Quiz notes, then expand
**More checks · Nerve relationships**. The original question is unchanged. Only
the active additional check is shown; its answer/explanation appears after
**Check answer**. Correct feedback offers **Practise again**; incorrect feedback
offers **Try again**. Attempts reset when the selected content changes. Opening
a tour quick check inherits the existing camera/link pause; no autoplay is added.

Eight original questions are bound to 18 complete retained muscle identities:
bilateral flexor digitorum superficialis/profundus, both flexor carpi ulnaris
heads, supinator, adductor longus, sartorius and tibialis anterior/posterior.
This teaches usual motor relationships, not a new peripheral-nerve model.
Existing biceps femoris long/short-head questions are preserved. No absent limb
nerve surface, branch course, independent head motor territory, movement, flow,
diagnosis or patient-space registration is inferred.

## Clinical review and validation

Review worksheets display every added prompt, option, key, explanation, source
and limitation. Their teaching/material fingerprints change, so earlier teaching
approvals cannot approve this extension. Geometry and other topics do not change.
The current content schema permits this optional field only on keyed draft Quiz
sections; the legacy schema remains untouched. Unknown fields, ambiguous answer
keys, duplicate keys and unsafe citation URLs are refused.

The owner should verify factual supply/terminology, branch-versus-parent wording,
the profundus split, source identity and relevance of head-level presentation.
These are usual-anatomy questions, not claims about prevalence of variants or
motor territories in an individual. Clinical approval requires the exact current
worksheet revision. No acquired scan or mask is changed. Website copies must be
updated through the normal generated-module import before claiming visibility.

Run `npm run limb-nerve-quiz:test` for source, answer behavior and worksheet
coverage; `node scripts/test-limb-nerve-quiz-discovery.mjs` additionally checks
all 18 learner entry points, bilateral selection reset keys and exam concealment.
These are synthetic component checks, not signed-in browser/GPU acceptance.
