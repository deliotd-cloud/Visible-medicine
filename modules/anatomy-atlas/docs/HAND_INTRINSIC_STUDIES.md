# Hand intrinsic-muscle study views

Two hand-only recipes reuse the existing Study menu and unchanged BodyParts3D
surfaces. They do not add a new toolbar, model, licence obligation or paid service.

- **Thenar/adductor comparison:** supplied abductor pollicis brevis, opponens
  pollicis and the two named adductor-pollicis heads, with first-metacarpal context.
- **Interosseous/lumbrical comparison:** supplied grouped lumbrical, palmar
  interosseous and dorsal interosseous selections, with metacarpal context.

Choose Left or Right for a closer view, select a supplied structure, set it aside,
and use Undo to restore it. Bone context is selectable in these root-region
views and remains present during separation unless explicitly removed. Return
separation to zero before interpreting the original spatial relationships.
This differs intentionally from non-selectable context in certain nested viewers.

## Source and review limits

The source-labelled muscle groups remain groups: these recipes do not create
individually numbered lumbricals/interossei, tendons, sheaths, aponeurosis or
neurovascular anatomy. Quarantined flexor-pollicis-brevis surfaces remain excluded.
These are selected-surface study views, not complete thenar dissections or
physiological simulations. No procedure or safe dissection plane is implied.

Admission binds exact identities, source files, laterality, catalogue metadata
and bundle hashes. Left/right filters retain only the chosen side; Both shows
both references. Focused practice uses the supplied named targets rather than
the context bones. Existing hand vascular/bone recipes, all teaching and original
geometry are preserved by exact historical replay. No stored clinical approval is
migrated. The owner's revision-bound anatomical and clinical review is required.

The study descriptions explain existing source selections and UI operations;
no external images, scans or factual teaching passages are imported. Existing
BodyParts3D attribution and all current access boundaries remain unchanged.

`npm run hand-intrinsic-studies:test` verifies exact source admission, recipe
transition, previous teaching/recipe preservation and interaction/link regressions.
See the dated coordination checkpoint for actual test/browser/build results,
GitHub/D recovery and publication status; this document alone proves none of them.
