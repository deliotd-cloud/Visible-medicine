# Short ciliary source group and unilateral presentation

Source-only implementation, 17 September 2026. Not clinically approved or newly
deployed. Original-source research and licensing: `SHORT_CILIARY_SOURCE_REVIEW.md`.

## What changed

One canonical FMA7041 selection adds the original FJ1319/FJ1370 pair: 1,240 source
triangles, neither repaired nor mirrored. Both uses the aggregate render node;
Left/Right use the corresponding complete original-file node. These alternative
render nodes are never drawn together for the same selection. They retain one
canonical ID and full ordered sources; no new sided FMA concepts are invented.

The existing study-window list includes **Short ciliary source & orbital context**.
It omits the skull, which otherwise occludes this small orbital view, and retains
the available ganglia, communicating branches, long ciliary nerves, eyeballs and
lateral recti. Ordinary Explore, Dissect, isolate/frame, labels, separation and
side controls remain; no additional toolbar or top-level navigation is added.

Canonical catalogue records continue to supply teaching, practice identity,
imaging links, source hashes and clinical-review materials. Separate ephemeral
presentation records supply scene geometry, visible bounds, selection-reveal
tests, label anchors, focus, arrangement, origin guides and scene framing. Batch
and individual draw paths consume the same presentation node and canonical pick
ID. Existing records without presentation parts preserve their prior side policy.

Bookmarks include presentation metadata as well as bundle hashes. The GLB also
embeds the mapping, and export checks bind that mapping to the retained catalogue.
The review worksheet exposes each original file, checksum, display side, render
node, bounds and anchor; its response parser rejects malformed part descriptions.
None of these fingerprints is a radiologist signature or patient registration.

## Evidence and reproduction

- `npm run short-ciliary:test`: reconstructs the GLB and retained original bytes,
  verifies source holds, exact vertices/faces, per-side geometry, six deep links,
  invalid part mutations, legacy-side policy and the recorded content transition.
- `node scripts/validate-body-batch-component.mjs`: executes the actual Bundle
  with controlled hooks, including real source-node transitions in individual
  and batched draw paths and canonical click identity. This is not GPU acceptance.
- `content/short-ciliary-transition.json` pins the addition and proves the prior
  1,102 canonical records, 9,918 teaching topics, shoulder teaching and recipes
  unchanged after removing only the exact recorded addition. Historical helpers
  reconstruct that prior state only for old regression suites, never at runtime.
- Main-workspace `work/check-short-ciliary-browser-20260917.mjs` inspects actual
  desktop/mobile scene inputs, direct links, isolate/frame, Explore/Dissect and
  side switches. Its JSON/screenshots are separate from clinical/device review.
- Production build lossless model-delivery checks include the new source GLB.
  Existing original model files are not rewritten. Current source requirements
  and review renderer revision are regenerated through the established pipeline.

Original OBJ recovery files are under `content/sources/short-ciliary`; only the
source catalogue/GLB live under public model delivery. The local research viewer
and full ownership audit remain in the D-drive recovery evidence, not public
website routes. No scan/mask, patient identifier, publisher media or new fee is
introduced.
