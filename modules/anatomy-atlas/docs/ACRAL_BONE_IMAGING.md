## What the learner can inspect

| Region/structure | Imaging emphasis |
| --- | --- |
| First metacarpal | Distinguish thumb CMC, MCP and thumb-specific orientation |
| Central metacarpals | Trace the named carpal base partners, shaft, neck and head |
| Fourth/fifth metacarpals | Include the hamate and neighbouring CMC region, not only the metacarpal |
| Finger proximal phalanx | MCP capsule/extensor hood versus palmar flexor structures |
| Finger middle phalanx | PIP versus DIP; central slip, superficialis and continuing profundus |
| Finger distal phalanx | Articular base versus tuft; terminal extensor versus profundus insertion |
| Thumb phalanges | MCP collateral/aponeurotic relationships; one IP joint and no middle phalanx |
| First metatarsal/hallux base | First MTP plantar supporting complex differs from lesser-toe plates |
| Second metatarsal | Recessed base and Lisfranc context; loaded versus unloaded acquisition |
| Third/fourth metatarsals | Base and articular extension, shaft/head, marrow versus soft-tissue findings |
| Fifth metatarsal | Tuberosity versus proximal shaft; developmental apophysis caution |
| Lesser toe proximal phalanx | Distal plantar-plate attachment and neighbouring tissues on successive images |
| Middle/distal toe phalanges | Explicit joint/segment identity and small-tissue/partial-volume limitations |

The actual displayed selection contributes its pre-existing anatomical landmarks,
side/digit/segment and limitations. Camera position does not change the identity.
These notes guide correlation with an existing acquired study, not a prescribed
acquisition, diagnostic conclusion, fracture classification or measured stability.
Bone meshes are not separately validated cortex, marrow, nail beds, tendon
insertions, ligaments, cartilage or plantar plates. No new geometry or panels.
