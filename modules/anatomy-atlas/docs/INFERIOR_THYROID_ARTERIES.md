# Inferior thyroid sources and neck arterial navigation

In **Head & neck**, **Shoulder & arm**, **Thorax** or **Whole body**, search **inferior thyroid artery** and select a side. The two original source groups add 962 unchanged triangles to the 1,058-selection display catalogue. The historical 1,022-record catalogue and all earlier meshes remain unchanged.

**Arterial connections** links each selection with the same-side thyrocervical trunk. **Show available connections & bones** keeps these artery groups with the hyoid and seven cervical vertebrae where available in the selected region. It does not expose the whole skull. Existing selection, labels, hide/Undo/Redo, clipping, transparency, isolation and separation controls are reused; no new permanent toolbar. At 0% separation the original source positions are restored.

## Teaching and clinical review

Original brief Anatomy/Function/self-check drafts use the [TTUHSC El Paso anterior-neck reference](https://anatomy.ttuhscep.edu/nervous_system/antneck_tables.html). No passage, table or diagram is redistributed. The typical parent is the thyrocervical trunk; a link is not a validated source junction or continuous lumen. Clinical, Pathology, CT, MRI, X-ray and Ultrasound remain explicitly pending.

Complete **source definition** does not mean complete **anatomical vessel**. Thyroid/parathyroid tissue, recurrent laryngeal nerves, all glandular branches, lumens and territories are not supplied by this addition. Specialist review must assess identity, course/extent, artefacts, proximity to retained neck sources, misleading surface contacts and the draft copy. This is not an operative view, perfusion map, embolisation/ligation target, CT angiogram or registered patient scan. Real browser/mobile/clinical review is separate from automated checks. Sign-off must reference this exact source, renderer and content revision.

Checks: `node scripts/audit-inferior-thyroid.mjs --check`, `node scripts/export-inferior-thyroid.mjs --check`, `node scripts/pin-thyroid-context.mjs --check`, `node scripts/validate-inferior-thyroid.mjs`, and `npm run arterial-connections:test`. The new validator checks every ordered face corner, original source-vertex anchors, laterality, 16 study links, 79 source-admission rejection cases and same-side parent identity. The shared graph validator exercises actual component and parent actions, independent context expectations, invalid catalogues and reversible isolation.

## Muscle-part candidates not admitted

Four other missing reference pieces were retrieved and [screened for source condition](muscle-part-condition-audit.json): clavicular parts of pectoralis major and superficial heads of flexor pollicis brevis, both sides. Each clavicular source has 13 components/9 duplicate faces; each thumb source has 15 components/11 duplicate faces. All 5,144 original triangles and four original files are retained as offline review evidence under `content/prototypes/muscle-part-condition`.

No muscle source is imported, repaired, relabelled, joined or silently reduced to its largest component. This preliminary check is not a complete ownership/overlap/laterality assessment; it does not create a new formal source hold. They remain in the source/anatomical review queue. `node scripts/audit-muscle-part-condition.mjs --check` verifies the exact retained evidence. A future derivative requires documented justification and independent review.
