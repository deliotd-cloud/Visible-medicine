# Spinal-muscle plain-radiograph orientation drafts

This text-only batch covers 32 named anatomical families across 56 remaining Atlas
sources with predecessor identities pinned at `4e9f53851cdc55b89ca8bfc1b6d07e19445fc2ad`.
It supplies short original comparisons between the assembled 3D anatomy and bony
orientation available on a plain radiograph. The six existing upper-cervical
projection lessons remain separate. The resolver admits only exact complete
source identities and the X-ray topic, never a region/name match. Source pins
retain names, laterality, ordered original components, model bundle, frame,
licence and prior pending lesson. Changed identities return no specialist lesson.

`npm run spinal-muscle-xray:test` replays the actual predecessor from immutable
Git source and compares all 9,936 root lessons and 1,104 review worksheets.
It expects only 56 X-ray lessons/worksheets to change, preserving all six earlier
cervical drafts. Altered source fields, forged worksheets and stale teaching
decisions must refuse before any storage call. This describes the test contract;
actual pass/fail receipts are recorded in the delivery checkpoint.

Trapezius parts, erector-spinae columns, transversospinal and small segmental
families, suboccipital muscles, posterior serratus and short rib elevators have
family-specific orientation. Aggregate source labels remain aggregate: spinalis,
thoracic rotator and lumbar intertransversarii gain no inferred side, slip or
vertebral-level assignment. Exact source-mesh attachment geometry is not asserted.
The lateral lumbar intertransversarii are oriented between neighboring vertebral
levels, never left-to-right across the spine. The medial family is kept beside
posterior lumbar arches without an unverified process-to-process attachment claim.

The projection cautions are educational inferences from conventional anatomy and
the AAOS explanation of radiographic projection and limited soft-tissue detail.
They are not studies validating visibility of these source meshes. A plain film
does not delineate an individual muscle boundary or establish attachment or
tendon integrity. The assembled model is neither a simulated radiograph nor a
registered patient scan. This batch adds no images, traced figures, copied tables,
external datasets, numeric injury criteria, diagnosis or clinical recommendation.
In particular, the Lhuaire 2022 non-commercial asset is excluded.

All facts remain drafts until revision-bound radiologist sign-off. No clinical,
browser, hosted or release acceptance is claimed here. Existing source-model
holds, independent access and the broader Atlas goal remain in force.
