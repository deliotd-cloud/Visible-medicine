# Neural Anatomy and identity-routing correction

8 September 2026: eleven new Anatomy drafts and six corrected Function drafts across eleven existing nervous-system representations. Five bilateral definitions and one brain aggregate use 69 source components. Existing controls, geometry, sources, dependencies and review state are unchanged.

## Corrected defect

The old Function fallbacks tested whether a source name contained `trochlear nerve` or `ciliary ganglion`. Those substrings also matched infratrochlear/supratrochlear nerves and the nasociliary communicating branches. Consequently four sensory branches displayed CN IV motor teaching and two sensory roots displayed ganglion-relay teaching. All six erroneous descriptions were already labelled draft, so readiness counts alone did not reveal the defect.

The six affected identities are FMA52698/FMA52699, FMA52643/FMA52644 and FMA52673/FMA52674. They now receive exact-ID sensory teaching. Legacy trochlear and ganglion fallbacks also use exact FMA lists, never substring matching. Tests exercise each corrected side and an unknown-ID/name impostor. Correct existing Function descriptions for CN IV, the two ganglia and the brain remain byte-for-byte unchanged.

## Source scope

All eleven names, FMA IDs, categories, laterality and file memberships were independently checked against cached official BodyParts3D v4 ISA/PART-OF index rows. Ten one-file entries comprise paired infratrochlear nerves, supratrochlear nerves, nasociliary sensory roots, trochlear nerves and ciliary ganglia. Brain FMA50801 is a 59-file PART-OF aggregate. It is not 59 validated functional regions; midline metadata does not make the brain anatomically symmetric.

The new resolver requires nervous-system membership, head-neck primary/secondary region, exact FMA, category, laterality and an authored topic. All eleven receive Anatomy; only the six proven Function collisions receive corrected Function. Return arrays are detached and source coverage warnings remain. No new roots, fibres, territories, nuclei, branches or tissue interiors are modelled.
