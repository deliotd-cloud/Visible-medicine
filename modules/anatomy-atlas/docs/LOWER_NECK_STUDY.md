BodyParts3D surfaces. It is available through the current Study windows & focuses
library, with no additional permanent toolbar or independent viewer.

Each side contains common carotid artery, internal jugular vein, subclavian artery,
subclavian vein, and anterior/middle/posterior scalene source surfaces. Existing
sternocleidomastoid and omohyoid provide removable context. Both sides retains18
entries; Left or Right retains9. Focused practice uses14/7 target entries, not the
four/two context muscles. These counts describe source entries, not completeness.

Select a surface to use its existing teaching, Remove and Undo, or Extract selected.

arterial origins and vessel endpoints are not clipped to a newly invented boundary.

complete neck, clinical procedure, ultrasound window or registered CT/MRI.
