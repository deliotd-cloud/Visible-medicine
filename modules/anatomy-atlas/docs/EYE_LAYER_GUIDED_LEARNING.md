# Eye-layer guided learning

Four optional source-bound draft stops in each existing eye study: anterior
cornea/iris, lens/support, vitreous in context and wall layers. Open **Guided
learning** beside the model, then **Start eye walkthrough**. Previous/Next changes
the existing visibility preset and selected component while using the shared
1.8-second eased camera sweep. Other visible components fade; nothing translates.
End restores the previous manual layers/history, separation, view and camera.

The complete retained parent/child teaching pins and bundle hash must match.
Missing or altered components refuse the whole guide, not a shortened substitute.
Both sides use their own children. The absent right anterior-chamber representation
remains absent; retina/finer layers and validated optical/surgical planes remain
out of scope. No new meshes, textures, fonts, dependencies or scan images.

Reduced-motion preference defaults conservatively to no sweep until known.
Hidden-page, renderer-loss and loading/failure states pause motion and deny
step changes; End remains available. Manual controls and imaging-selection
publishing are suspended during guidance. References reuse the existing eye
links, with original brief captions grounded in the existing authored notes.
The National Eye Institute reference was accessed to verify the general cornea,
iris and lens descriptions; NCBI's existing textbook reference returned a browser
challenge in this session. No reference images or verbatim paragraphs were copied.

Clinical Review includes every caption, selected source ID, visible set, preset,
camera direction, motion setting and limitation in **guidedLearning**. The full
guide and reference titles enter teaching fingerprints for all 15 eye children.
A new required guided-learning checklist item prevents old topic-only sign-off
covering these sequences. The other 93 nested teaching packets stay unchanged;
all 108 source identities, earlier topics/self-checks and source holds remain.
Normal renderer regeneration requires geometry re-review. Imaging remains
unavailable without its own validated series/registration and access.

Tests exercise source mismatch/missing children, detached data, actual component
callbacks for both eyes, restore/limits/reduced motion/readiness and review
revision refusal before storage. Controlled component tests are not browser/GPU
or clinical evidence. Signed-in browser interaction, visual readability and
revision-bound radiologist sign-off remain required. Publication is not implied.
