# Non-overlapping drawer return control

27 September 2026. The regional/whole-body drawer's Return to model button
previously used position:sticky; bottom:0. In a short scrolling Practice panel it
could overlay answers or Check answer and consume a tap intended for them.
It now follows the content in normal flow. No new scroll container or focus
mechanism was introduced; existing close controls, Escape, focus management and
keep-mounted answers remain intact. Both Systems and Structure info/Practice
drawers share the correction, including focused desktop drawers.
