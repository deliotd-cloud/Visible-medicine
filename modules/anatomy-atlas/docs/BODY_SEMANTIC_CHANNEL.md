# Root-body semantic selection channel

Local source milestone, 14 October 2026. The original head/nested and separate
right-source specimen protocols remain unchanged. A separate opt-in root-only
leg/thigh channel supports future explicit native MRI handoffs.

## Boundaries

Only an embedded same-origin parent window can request a snapshot or focus.
Version, exact Atlas commit, region, fresh session, monotonic sequence/command and
public anatomical ID/source/laterality bind every exchange. No scan identity,
coordinates, URL, access token, entitlement or approval enters this protocol.

The root handler resolves a unique canonical current-region record and unique
source bundle. It refuses unloaded/failed/invisible/system-disabled targets,
practice, guided learning, nested or independent specimen views, hidden pages
and unavailable rendering. Accepted focus changes only the ordinary named
selection; it does not reset camera/dissection, load another scan or validate
spatial registration. A focus acknowledgement alone is not selection proof.

Root snapshots use canonical records, never presentation fragments. Hidden or
removed selections cannot be reported as a current selected root. The channel
is closed on hidden/pagehide, and reconnects with readiness on return; old
sessions do not revive. Loading recovery also requires a fresh handshake.
