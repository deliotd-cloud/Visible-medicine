# Upper-limb source screen — 18 September 2026

A bounded primary-source search sought original upper-limb ligament, cartilage
or peripheral-nerve meshes. No dataset was admitted and no files were downloaded.
This is not evidence that no usable source exists anywhere.

- [BLAB Roboshoulder v4](https://zenodo.org/records/21102041) exposes ten shoulder
  archives and a description PDF. Its description concerns CT-derived bones,
  landmarks and measured kinematics, not the missing soft-tissue surfaces.
  The retrieved record's Rights/License section did not supply usable terms.
  File availability and an Open badge do not establish commercial reuse rights.
- [CEINMS-RT UpperLimbModel](https://github.com/CEINMS-RT/UpperLimbModel) exposes
  a musculoskeletal simulation model, but its MoBL-ARMS notice restricts reuse
  to non-commercial purposes unless separately licensed. It is not an admitted
  source of the requested ligament, cartilage or nerve surfaces.

Existing BodyParts3D pelvic-floor, valve and other identity holds remain intact.
The previous SPARC, Cevallos and mixed-provenance Z-Anatomy decisions were not
reopened. New component-specific rights and source evidence are needed before
these candidates can change an admission decision. No guessed anatomical
surface or imported kinematic muscle path has been substituted for missing tissue.
