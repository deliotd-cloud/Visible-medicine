# Median cubital vein: X-ray context draft

Two retained selections, right FMA22964 and left FMA22965, receive the same
limited contrast-venography lesson through complete immutable source identities.
Only X-ray teaching changes; geometry, other topics, questions and tours do not.
No acquired image is linked. This is not a new venographic anatomy dataset.

## Evidence and limits

- Jo et al., Medicine 2025, DOI 10.1097/MD.0000000000043727:
  https://pmc.ncbi.nlm.nih.gov/articles/PMC12338226/
  Injection-site identity is not a labelled image-segment identity. The selected
  access-creation cases do not establish normal plain-film visibility.
- Ukoha et al., 2013, PMID 23377482:
  https://pubmed.ncbi.nlm.nih.gov/23377482/
  Surface-observation evidence supports naming/variation only, not radiography.

Accessed 13 October 2026. The 2025 article states CC BY 4.0, but no article figure,
table, text, scan, model or dataset is imported or adapted. The new code and
independently written factual teaching use the project MIT licence; existing
BodyParts3D attribution is unchanged. No dependency, font, service or fee added.

The ambiguous median/medial-cubital terminology in a separate 2008 dialysis case
is deliberately not used as a secure image identity. Both median antebrachial
X-ray placements and 12 small-artery placements remain pending. Do not infer
continuity, flow, patency, procedural suitability or patient-space registration
from these reference meshes.

## Review and verification

`npm run median-cubital-xray:test` verifies the exact two pending-to-draft
transitions, full identity refusals, preserved earlier teaching and source
geometry, altered worksheet rejection and stale/forged decision rejection
before storage. The earlier forearm vascular test replays its completed Git
epoch with all original expectations retained; the new test checks live state.

Normal generated website integration is a separate checkpoint. Radiologist
review must identify the actual source, teaching revision and supported scope;
draft status is not approval or clearance of any future patient image.
