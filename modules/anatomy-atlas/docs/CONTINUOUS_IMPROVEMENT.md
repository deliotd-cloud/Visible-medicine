# Continuous atlas improvement plan

## Objective and boundaries

Improve anatomical coverage, educational depth, functionality and diagrammatic presentation while preserving easy navigation, official Visible Medicine branding and minimal scrolling. Prepare interoperable links to CT, MRI, X-ray, ultrasound and lectures without claiming those external integrations already exist.

Preserve source IDs/registration, clinical-review separation, private publishing access and commercial-use notices. No paid AI API, asset purchase, guessed nerve route, fabricated patient scan or invented approval. The main website, CT/MRI project and course packages are read-only references unless separately authorized. Remote GitHub work is deferred; a same-PC module snapshot is not an off-device backup.
