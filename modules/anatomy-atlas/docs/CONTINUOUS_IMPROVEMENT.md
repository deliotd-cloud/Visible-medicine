# Continuous atlas improvement plan

## Objective and boundaries

Improve anatomical coverage, educational depth, functionality and diagrammatic presentation while preserving easy navigation, official Visible Medicine branding and minimal scrolling. Prepare interoperable links to CT, MRI, X-ray, ultrasound and lectures without claiming those external integrations already exist.

Preserve source IDs/registration, clinical-review separation, private publishing access and commercial-use notices. No paid AI API, asset purchase, guessed nerve route, fabricated patient scan or invented approval. The main website, CT/MRI project and course packages are read-only references unless separately authorized. Remote GitHub work is deferred; a same-PC module snapshot is not an off-device backup.

1. Inspect current changes and relevant source/rights evidence; preserve unrelated user work.
2. Implement one coherent improvement with a clear scope and acceptance test.
3. Run affected helper/component/content/geometry safeguards and a production build. Check hashes and obligations when assets or dependencies change.
4. Regenerate material fingerprints only for changed material; never create clinical approvals.
5. Save the exact source and privately publish when in scope, retaining access policy. Verify the module-only local recovery snapshot; report separately whether any off-device destination is actually verified. Do not retry deferred GitHub access without new direction.
6. Record verified results, limitations and next executable work. Keep the overall goal active while meaningful authorized work remains.
