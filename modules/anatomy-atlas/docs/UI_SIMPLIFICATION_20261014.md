# Desktop UI simplification — 14 October 2026

The learning modes display Explore, Dissect, Guided learning (where supported),
and Quiz. Quiz retains the existing `practice` state and assessment restrictions.
The labels, separation slider and reset remain immediately available; the unchanged
layout choices are inside Advanced view. Existing selection, guide pause/return,
camera and separation handlers are retained.

Body and shoulder review worksheets now include a source-bound visual inspector
beside the existing decision controls at desktop widths. Body inspection waits
for the parsed exact material and retires when its selection changes. Cancelling
dirty navigation preserves both worksheet and inspector. Shoulder Previous/Next
retains the existing per-structure drafts; navigation does not save or approve.
Hide model unmounts the frame. The larger inspector remains available separately.
The worksheet name/revision are visible beside the model: in-model selection
changes inspection only and does not switch the worksheet or its decision scope.

The normal website importer maps inspection to its authenticated, compact review
model presentation. Missing models stay unavailable; no default anatomy or home
page is substituted. The compact host keeps existing query validation and private
parent authorization but omits repeated navigation and worksheet links. Standalone
review remains available. Source previews use the original Atlas routes.

No model, anatomy teaching, source rights, scan, mask, patient registration,
entitlement, approval record, fee or dependency is changed. Display revisions
advance conservatively; existing private decisions are not migrated. Focused
component/navigation tests and build evidence are recorded by the coordinator in
`F:/VisibleMedicine/staging/20261014-ui-simplification`. Browser, WebGL, 1280px+
visual acceptance, zoom, touch and clinical sign-off remain separate checks.
