# Source-bound intrinsic laryngeal muscle teaching

This increment replaces only the Anatomy and Function drafts for seven exact
source selections: bilateral posterior crico-arytenoids, bilateral lateral
crico-arytenoids, the transverse arytenoid, and bilateral oblique arytenoids.
The four teaching families remain distinct. Every match requires the complete
catalog identity, not an FMA identifier alone.

The source geometry, bundle, recipes, study group, guided navigation, holds,
and the other 9,904 topic payloads are unchanged. The lessons describe static
source-bound relationships and actions; they do not add movement, imaging,
nerve segmentation, operative guidance, clinical approval, or patient data.
Anatomical and teaching review remains pending, including revision-bound
radiologist sign-off before release claims.

`npm run laryngeal-muscle-teaching:test` checks the immutable baseline and
transition, all 14 replacements, 14 server-rendered notes, all 1,102 schema
records, exact-match rejection, bundle geometry hash, and strict historical
before/after/mixed/drift states. Its machine-readable report is
`docs/laryngeal-muscle-teaching-validation.json`.
