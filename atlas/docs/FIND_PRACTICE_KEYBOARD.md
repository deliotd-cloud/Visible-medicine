# Keyboard selection during find practice

The regional/whole-body find-on-model exercise now includes an optional Keyboard selection disclosure. Previous and Next highlight one already displayed structure; Choose highlighted submits it through the existing answer-once practice reducer. No candidate names or IDs appear in the controls. The controls use scene/catalogue order rather than the order of requested answers.

The cursor changes only the highlight. It does not isolate, move or rename anatomy, change the camera, enable labels, or create an imaging selection. Mouse selection remains available. Missing, hidden, disabled-system and context-only anatomy is excluded. Renderer or required-model loss pauses the controls. A new question/session cannot inherit a highlight or accept a captured old callback; feedback and exit remove the cursor.

This enables sighted keyboard users to inspect and answer the existing spatial exercise. It is not a nonvisual substitute for identifying a 3D shape, and it does not establish an accessibility certification or clinically validated assessment. Existing name/reasoning question formats and source-bound teaching remain unchanged.
