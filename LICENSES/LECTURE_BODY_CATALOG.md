# Lecture body-structure index — 21 October 2026

`lib/lecture-body-catalog.json` is a compact derivative of the already bundled,
source-bound Atlas display catalogue. It retains 1,104 public root identities,
display names, existing aliases, side/region, bundle hashes and source limits.
It contains no meshes, scans, masks, private notes or new medical teaching.
Adaptation: selecting public display metadata, grouping repeated source hashes
and serializing a small search index. No source institution endorsement is implied.
